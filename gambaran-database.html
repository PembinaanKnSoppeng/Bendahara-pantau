Ekosistem Data & Arsitektur SIMANTU

Sistem Informasi Monitoring Tunjangan Kinerja dan Uang Makan Kejaksaan Negeri Soppeng memanfaatkan basis data PostgreSQL modern di Supabase Cloud dengan arsitektur Single-State Pipeline dan protokol Change Data Capture (CDC) Realtime WebSockets.

Lapisan Input & Kontrol

Admin Bendahara

Portal kontrol terotentikasi untuk mengelola siklus pencairan 8 tahapan.

  • 🔐 Supabase Auth (JWT Session)
  • ⚡ Aksi Lanjut Tahap / Mundur
  • ⚠️ Prosedur Tolak & Revisi KPPN
  • 🗂️ Arsip Otomatis Periode Baru
Mesin Utama (Cloud Database)

Supabase PostgreSQL Hub

Pusat persistensi data dengan latensi rendah dan auto-broadcast.

  • 🎯 Pola Singleton (id = 1, Query O(1))
  • 📡 Realtime Engine (WebSockets)
  • 📦 Tabel Riwayat Pencairan (Arsip)
  • ⭐ Tabel Rating Indeks Kepuasan
Lapisan Konsumsi Publik

Pegawai Kejari Soppeng

Tampilan ramah pengguna via Smartphone (PWA) & Browser PC tanpa refresh.

  • 📱 Auto-Update Tanpa Reload Halaman
  • 📊 Progress Bar Visual 0% - 100%
  • 🎉 Animasi Confetti Saat SP2D Cair
  • 💬 Integrasi Bantuan WhatsApp
