BAHAN PAPARAN PERANCANGAN BASIS DATA

SISTEM INFORMASI MONITORING TUNJANGAN KINERJA & UANG MAKAN (SIMANTU)
KEJAKSAAN NEGERI SOPPENG

A. ARSITEKTUR DAN GAMBARAN VISUAL BASIS DATA

Basis data SIMANTU dirancang berbasis cloud memanfaatkan sistem manajemen basis data relasional PostgreSQL (Supabase). Sistem mengadopsi prinsip Single-State Synchronization untuk status yang sedang diproses secara realtime, serta Historical Logging untuk pengarsipan rekam jejak pencairan masa lampau.

TABEL 1: status_tukin_global
• id : BIGINT (PK, Fixed = 1)
• periode : TEXT
• current_step : INTEGER (Tahap 1-8)
• estimasi : TEXT
• catatan : TEXT
• is_rejected : BOOLEAN
• updated_at : TIMESTAMPTZ
→
TABEL 3: arsip_pencairan
• id : BIGSERIAL (PK, Auto-inc)
• periode : TEXT
• jenis : TEXT ('Tukin' / 'Makan')
• tanggal_cair : TIMESTAMPTZ
(Menyimpan histori periode setelah SP2D selesai)
↓ (Saat Bendahara Reset Bulan Baru, periode disalin ke Arsip)
TABEL 2: status_uang_makan_global
• id : BIGINT (PK, Fixed = 1)
• periode : TEXT
• current_step : INTEGER (Tahap 1-8)
• estimasi : TEXT
• catatan : TEXT
• is_rejected : BOOLEAN
• updated_at : TIMESTAMPTZ
→
TABEL 4: rating_kepuasan
• id : BIGSERIAL (PK, Auto-inc)
• periode : TEXT
• jenis : TEXT ('Tukin' / 'Makan')
• rating : INTEGER (Skor 1 - 5)

(Menampung evaluasi kepuasan aparatur)

B. STRUKTUR DAN KAMUS DATA TABEL BASIS DATA

1. Tabel: status_tukin_global
Fungsi: Menyimpan data pelacakan proses pencairan Tukin yang aktif (Record tunggal ID=1).

No Nama Kolom Tipe Data Kunci (Key) Keterangan
1 id BIGINT Primary Key Bernilai tetap 1 (Pola Singleton $O(1)$)
2 periode TEXT - Bulan pencairan (misal: "April 2026")
3 current_step INTEGER - Angka tahapan aktif (nilai 1 s/d 8)
4 estimasi TEXT - Perkiraan waktu (misal: "1-2 Hari Kerja")
5 catatan TEXT - Pengumuman bendahara atau info revisi
6 is_rejected BOOLEAN - Status penolakan KPPN (True = Ditolak)
7 updated_at TIMESTAMPTZ - Timestamp sinkronisasi data terakhir

2. Tabel: status_uang_makan_global
Fungsi: Menyimpan data pelacakan proses pencairan Uang Makan yang aktif (Record tunggal ID=1).

No Nama Kolom Tipe Data Kunci (Key) Keterangan
1 id BIGINT Primary Key Bernilai tetap 1 (Pola Singleton $O(1)$)
2 periode TEXT - Bulan uang makan (misal: "Maret 2026")
3 current_step INTEGER - Angka tahapan aktif berjalan (1 s/d 8)
4 estimasi TEXT - Target penyelesaian tahapan
5 catatan TEXT - Papan pengumuman informasi bendahara
6 is_rejected BOOLEAN - Status penolakan KPPN (True = Ditolak)
7 updated_at TIMESTAMPTZ - Timestamp pembaruan data terakhir

3. Tabel: arsip_pencairan
Fungsi: Menyimpan histori periode masa lampau yang telah sukses terbit SP2D.

No Nama Kolom Tipe Data Kunci (Key) Keterangan
1 id BIGSERIAL Primary Key Nomor urut riwayat auto-increment
2 periode TEXT - Periode yang telah sukses cair
3 jenis TEXT - Kategori hak: 'Tukin' atau 'Uang Makan'
4 tanggal_cair TIMESTAMPTZ - Tanggal pencairan resmi dibukukan

4. Tabel: rating_kepuasan
Fungsi: Menampung data survei evaluasi kepuasan layanan dari pegawai.

No Nama Kolom Tipe Data Kunci (Key) Keterangan
1 id BIGSERIAL Primary Key ID responden unik auto-increment
2 periode TEXT - Periode pencairan yang dinilai
3 jenis TEXT - Kategori: 'Tukin' atau 'Uang Makan'
4 rating INTEGER - Nilai kepuasan (Bintang skala 1 s/d 5)
5 created_at TIMESTAMPTZ - Waktu saat penilaian diserahkan

C. POIN UTAMA PENJELASAN SAAT PAPARAN

1. Efisiensi Tinggi (Single-State Pattern): Tabel status hanya memiliki 1 baris aktif (id=1), sehingga pembacaan status oleh puluhan pegawai berlangsung instan dalam hitungan milidetik tanpa membebani kapasitas server database.
2. Sinkronisasi Realtime Otomatis: Menggunakan protokol WebSocket bawaan Supabase, sehingga saat Bendahara memperbarui status di panel admin, tampilan di layar ponsel seluruh pegawai terbarui seketika tanpa harus menekan tombol refresh.
3. Pemisahan Data Transaksi dan Arsip: Data periode lama otomatis berpindah ke tabel arsip saat siklus baru dimulai, menjaga kebersihan data operasional sekaligus menyediakan histori yang akuntabel.
4. Akuntabilitas & Zona Integritas: Kehadiran tabel survei kepuasan memungkinkan pimpinan memantau indeks kepuasan pegawai atas kinerja pengelolaan keuangan satuan kerja secara objektif dan transparan.
